# ai-governance-docs

Documentation repository for AI governance content using MkDocs.

## Structure

- `docs/`: documentation pages
- `assets/images/`: image assets
- `assets/slides/`: slide assets
- `mkdocs.yml`: MkDocs configuration
- `.github/workflows/deploy.yml`: GitHub Pages deployment workflow

## Branches

The MkDocs setup is being prepared on `docs/mkdocs-setup`.
