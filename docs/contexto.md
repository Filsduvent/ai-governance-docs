# O Novo Contexto

!!! warning "Problema inicial"
    Em 2024, a empresa identificou um **data-driven problem**: dados dispersos, baixa integração e dificuldade de transformar informação em decisão confiável.

## 2024: organizar dados

| Situação | Impacto |
| --- | --- |
| Dados em múltiplas fontes | Visões diferentes da mesma realidade |
| Processos pouco integrados | Decisões mais lentas |
| Baixa rastreabilidade | Dificuldade para auditar e aprender |

## Resposta estratégica

!!! info "Datalake"
    O **datalake** foi construído para centralizar dados, integrar fontes e criar uma base comum para análise e decisão.
